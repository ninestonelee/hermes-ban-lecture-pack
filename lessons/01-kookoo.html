퇴근길 텔레그램 한 마디로 숏츠 초안 만들기

폰은 리모컨, 서버는 작업실. "숏츠 만들어"가 영상 파일로 돌아오는 구조

S 바로 활용6차시 PART 1 쇼츠 크론잡25분입문
원본 사례: @kookoo_Nick · 2026-10-21

한 줄 요약

퇴근길에 텔레그램으로 "숏츠 만들어"라고 보내면, 집 컴퓨터의 헤르메스가 대본, 음성, 자막을 넣은 영상 초안을 만들어 텔레그램으로 돌려준 국내 사례입니다.

원본 사례

2026년 10월 21일, 국내 사용자 쿠쿠(@kookoo_Nick)가 X에 올린 글입니다. 자기 집 윈도우 PC에 헤르메스 에이전트를 설치하고 텔레그램 봇과 연결해 쓰고 있다고 소개했습니다.

"폰으로 명령만 보내고, 진짜 작업은 컴퓨터에 시킴." (쿠쿠)

작성자가 밝힌 숏츠 제작 흐름은 이렇습니다.

  1. 텔레그램으로 주제를 보낸다
  2. 주제 분석
  3. AI가 대본 생성
  4. TTS(글을 목소리로 바꾸는 기술)로 음성 제작
  5. 자막 생성
  6. FFmpeg(영상 편집 프로그램)로 영상 편집
  7. 결과물을 텔레그램으로 전송

작성자는 "영상 소스 선정처럼 중간에 직접 확인하는 부분도 있다"고 밝혔습니다. 완전 자동은 아니고, 반복 편집 작업이 크게 줄었다는 이야기입니다. 숏츠 말고도 엑셀 10개 합치기, 사진 크기 일괄 변경, AI 뉴스 정리 파일 저장 같은 일을 같은 방식으로 시킨다고 했습니다.

같은 스레드 답글에는 윈도우 기준 설치 순서도 정리했습니다.

순서 작성자 안내 우리 수업에서는
1 PowerShell로 헤르메스 설치 라이트하우스 서버에 설치 완료
2 hermes setup, hermes model로 AI 연결 ChatGPT·Codex 구독 연결 완료
3 @BotFather에서 봇 만들고 토큰 받기 완료
4 hermes gateway setup으로 토큰과 내 숫자 ID 등록 완료
5 폰에서 명령 보내기 매일 하는 중

작성자의 결론 한 줄이 이 사례의 핵심입니다.

"중요한 건 AI가 갑자기 똑똑해지는 게 아니라, AI에게 실제로 일할 수 있는 도구를 쥐여준다는 거임." (쿠쿠)

참고: 작성자의 숏츠 스크립트 내용, 사용한 AI 모델, 제작 시간, 결과 영상은 공개되지 않았습니다.

왜 헤르메스반에 중요한가

  • 우리가 1차시부터 만든 구조와 똑같습니다. 다른 점은 작성자는 집 PC, 우리는 클라우드 서버라는 것 하나입니다. 작성자도 "클라우드 서버에 설치하면 집 PC 없이 운영 가능"하다고 썼습니다.
  • 집 PC 방식은 컴퓨터와 게이트웨이를 계속 켜 둬야 합니다. 서버 방식은 그 걱정이 없습니다. 우리가 왜 서버를 골랐는지 수강생이 스스로 납득하는 사례입니다.
  • 6차시 PART 1의 "이미지 합성형 쇼츠(카드뉴스 + 나레이션, 무료)"와 흐름이 같습니다. 이미 만든 카드뉴스 5장에 목소리와 자막만 붙이면 됩니다.
  • 5차시에서 배운 "미리보기 → 통과" 규칙을 영상에도 그대로 씁니다. 작성자도 중간 확인을 남겨 뒀습니다.

구조 한눈에 보기

  1. 1텔레그램 명령폰에서 "숏츠 만들어: 주제" 전송
  2. 2대본헤르메스가 30초 분량 대본과 카드 문구 작성
  3. 3음성Edge TTS로 한국어 나레이션 생성 (무료)
  4. 4자막과 편집FFmpeg가 카드 이미지 + 음성 + 자막을 세로 영상으로 합성
  5. 5미리보기텔레그램으로 영상 파일 전송, 내 답 기다림
  6. 6통과버퍼로 예약하거나 보관

폰은 "무엇을"만 말하고, "어떻게"는 서버가 합니다. 그래서 퇴근길 지하철에서도 영상 한 편을 맡길 수 있습니다.

핵심 개념

  • 게이트웨이: 텔레그램과 헤르메스를 잇는 통역사. 꺼져 있으면 봇이 조용해집니다.
  • TTS: 글을 목소리로 읽어 주는 성우. 헤르메스 기본값인 Edge TTS는 무료이고 키가 필요 없습니다.
  • FFmpeg: 명령어로 움직이는 영상 편집기. 사람이 마우스로 할 자르기, 붙이기, 자막 입히기를 글자 명령으로 합니다.
  • 허용 사용자 ID: 봇의 출입 명단. 내 숫자 ID만 적어 두면 다른 사람이 내 봇에 명령할 수 없습니다.
  • 스킬: 한 번 성공한 작업 순서를 저장한 레시피. 다음부터 "그 레시피대로"라고만 말하면 됩니다.

실습: 따라 하기

목표: 주제 한 줄을 보내면 30초 세로 영상 초안이 텔레그램으로 오게 만들기. 원본처럼 대본부터 편집까지 하되, 처음에는 카드 3장짜리 작은 버전으로 합니다.

1단계: 도구 점검 (3분)

봇이 영상 작업을 할 수 있는 상태인지 먼저 물어봅니다.

텔레그램 · 내 봇에게
영상 만들기 실습을 할 거야. 바꾸지 말고 점검만 해 줘.
1) 서버에 ffmpeg가 설치돼 있는지
2) 지금 TTS 설정이 무엇인지 (provider, 한국어 목소리 가능 여부)
3) 한글 폰트가 설치돼 있는지
없는 것이 있으면 무엇을 설치해야 하는지 목록만 보여 주고 내 승인을 기다려.

봇이 설치 목록을 보여 주면 확인 후 "설치해"라고 답합니다. 위험한 명령이면 헤르메스가 승인 버튼을 띄웁니다.

2단계: 한국어 목소리 맞추기 (3분)

텔레그램 · 내 봇에게
TTS를 무료 Edge TTS로 쓰고 한국어 여성 목소리(ko-KR)로 설정해 줘.
설정 전에 바꿀 내용을 먼저 보여 줘.
설정이 끝나면 "안녕하세요, 헤르메스반입니다"를 음성으로 보내 줘.

텔레그램에 음성 메시지가 오면 성공입니다.

3단계: 숏츠 초안 1편 만들기 (10분)

텔레그램 · 내 봇에게
숏츠 초안을 1편 만들어 줘. 주제: [내 블로그 최근 글 제목]
1) 30초 분량 대본을 쓰고, 카드 3장에 들어갈 짧은 문구로 나눠 줘
2) 카드 3장을 세로(1080x1920) 이미지로 만든다 (디자인.md 스타일)
3) 대본을 Edge TTS 한국어 목소리로 읽어 음성 파일을 만든다
4) ffmpeg로 카드 이미지 + 음성 + 하단 자막을 합쳐 mp4로 만든다
5) 완성 영상을 텔레그램으로 보내고, 대본도 글로 같이 보내 줘
바로 올리지 말고 내 답을 기다려.

처음에는 시간이 몇 분 걸릴 수 있습니다. 중간에 봇이 질문하면 답해 주세요.

4단계: 고치고 레시피로 저장 (5분)

영상을 보고 마음에 안 드는 점을 말합니다.

텔레그램 · 내 봇에게
수정: 자막 글자를 더 크게, 목소리 속도는 조금 빠르게.
고쳐서 다시 보내 줘.

만족스러우면 레시피로 저장합니다.

텔레그램 · 내 봇에게
방금 숏츠 만든 과정을 "숏츠초안" 스킬로 저장해 줘.
앞으로 "숏츠초안: 주제"라고 보내면 같은 순서로 만들고, 항상 미리보기 후 내 승인을 기다리게 해 줘.

5단계: 퇴근길 테스트 (4분)

폰만 들고 이렇게 보내 봅니다.

텔레그램 · 내 봇에게
숏츠초안: 겨울철 블로그 글감 3가지

봇이 조용하면 서버에서 아래 두 가지를 점검합니다.

서버 터미널
hermes gateway status
hermes gateway restart

응용 아이디어

  • 소상공인: "오늘의 메뉴 숏츠"를 매장 사진 3장과 음성 설명으로. 아침 크론잡으로 매일 초안 받기.
  • 1인 크리에이터: 블로그 새 글이 올라오면 자동으로 숏츠 초안까지. 밤 11시 크론잡에 4단계를 붙이기.
  • 강사: 강의 핵심 요약 30초 영상. 수업 다음 날 수강생 단톡방 공지용.
  • 직장인: 주간 보고 내용을 1분 음성 브리핑으로. 영상 대신 음성 파일만 받아 출근길에 듣기.
  • 부동산·보험 상담: 자주 받는 질문 1개를 카드 3장 숏츠로. 상담 전 고객에게 보내는 안내 자료.

수강생 미션

기본 미션

"숏츠초안" 스킬을 저장하고, 폰에서 주제 한 줄을 보내 영상 초안 1편을 받기. 제출물: 텔레그램 대화 캡처(명령 1장 + 영상 미리보기 1장).

도전 미션

밤 11시 크론잡에 숏츠 초안 만들기를 추가하고, "통과"라고 답하면 버퍼로 유튜브 쇼츠에 예약되게 하기(6차시 PART 2와 연결). 제출물: 버퍼 캘린더에 쇼츠 예약이 보이는 캡처.

체크리스트

  • 봇이 ffmpeg, TTS, 한글 폰트 상태를 점검해 보고했다
  • 한국어 음성 메시지를 받았다
  • 카드 3장짜리 세로 영상 초안을 받았다
  • "수정: ..."으로 한 번 이상 고쳐 봤다
  • 과정을 스킬로 저장했다
  • 바로 게시하지 않고 미리보기 후 승인하는 규칙을 유지했다
  • 허용 사용자 ID에 내 숫자 ID만 있는지 확인했다

주의할 점과 한계

  • 봇이 털리면 서버도 털립니다. 원문 댓글에서도 같은 질문이 나왔습니다. 허용 사용자 ID에는 내 숫자 ID만 두고, 봇 토큰이 노출되면 @BotFather에서 /revoke로 즉시 폐기합니다.
  • 집 PC 방식의 한계: 원문처럼 집 PC에서 돌리면 PC와 게이트웨이가 꺼지면 아무 일도 못 합니다. 우리 서버 방식은 이 문제가 없지만, 서버 용량을 영상 파일이 빨리 채웁니다. 오래된 영상은 주기적으로 지우게 하세요.
  • 비용: 헤르메스와 Edge TTS는 무료지만, 대본을 쓰는 AI 모델 사용량은 구독 한도를 씁니다. 영상 생성형(힉스필드 등)은 별도 유료입니다.
  • 저작권: 남의 영상, 음악, 이미지를 소스로 쓰지 마세요. 내 블로그 글과 직접 만든 카드 이미지만 씁니다.
  • 미검증 부분: 원작성자의 숏츠 스크립트, 모델, 제작 시간, 결과물 품질은 공개되지 않았습니다. 이 교재의 실습은 원문 흐름을 우리 환경에 맞게 다시 설계한 것입니다.
  • @userinfobot: 원문은 숫자 ID 확인에 이 제3자 봇을 안내했습니다. 우리 수업에서는 이미 등록을 마쳤으니 다시 쓸 필요는 없습니다.

강사 노트

시간 내용
0~4분 원문 소개: "폰은 리모컨, PC는 작업실" 한 문장, 집 PC와 우리 서버 비교 표
4~7분 1~2단계: 도구 점검, 한국어 음성 테스트 (전원 동시)
7~17분 3단계: 숏츠 초안 1편 (대기 시간에 구조도 설명)
17~22분 4단계: 수정 1회 + 스킬 저장
22~25분 5단계 시연과 미션 안내, PART 2(버퍼 쇼츠 예약)로 연결

시연 팁:

  • 영상 생성은 수 분 걸릴 수 있습니다. 강사 봇으로 미리 1편 만들어 두고, 수강생 영상이 오는 동안 그 영상을 보여 주세요.
  • ffmpeg나 한글 폰트가 없어 실패하는 경우가 가장 많습니다. 1단계 점검을 꼭 먼저 하세요. 자막 한글이 네모로 깨지면 폰트 문제입니다.

예상 질문:

  • Q. 집 컴퓨터에도 설치해서 같이 쓸 수 있나요? A. 가능합니다. 다만 집 PC는 켜져 있어야 하고, 봇 두 개를 운영하는 셈이라 관리가 늘어납니다. 우선 서버 하나로 충분합니다.
  • Q. 영상 품질이 너무 단순해요. A. 이미지 합성형은 무료인 대신 단순합니다. 힉스필드형(구독자용)은 6차시에서 따로 다룹니다.
  • Q. 봇이 영상 파일을 못 보내요. A. 파일이 너무 크거나 전송 시간이 초과된 경우입니다. "720p로 줄여서 다시 보내 줘"라고 요청하세요.
